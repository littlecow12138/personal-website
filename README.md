# 林晚 · 摄影师个人网站

基于 shadcn/ui Next.js 模板（preset `b5rR41Mtnc`）搭建的摄影师作品集站点。

## 字体

- **标题**：Syne（`--font-heading`）
- **正文**：Outfit（`--font-sans`）

## 本地开发

```bash
pnpm install
pnpm dev
```

## 占位图

所有图片目前为 picsum 占位，替换清单见 [PLACEHOLDERS.md](./PLACEHOLDERS.md)。

## 页面结构

1. Hero — 全屏主视觉 + 姓名与预约入口  
2. 简介 — 拍摄题材与工作方式  
3. 作品 — 精选网格  
4. 定价 — 三种档期报价（作品与联系之间）  
5. 联系 — 邮件链接
